# AI Pair-Programming Principles — NaferJ Portfolio

## Workflow

- One branch equals one logical concern.
- Fix accessibility, security, crashes, and broken user flows before polishing.
- Prefer user-facing progress over endless refactoring.
- Keep changes small enough to review and explain.
- Use one or two pull requests per sprint when practical.

## Working with AI

- The repository owner makes product and design decisions.
- Present two or three options when trade-offs materially affect the portfolio.
- Choose the simplest established approach for routine implementation details.
- Keep handoff context focused on the current task, stack, decisions, and blockers.

## Git

- The assistant never commits or pushes.
- The assistant never rewrites history or deletes branches without explicit approval.
- Pull requests are created manually by the repository owner.
